# Audiolibro

App audiolibro personale (PWA) per iPhone, pubblicata con GitHub Pages dalla cartella `docs/`.

- `docs/` — l'app web (quello che viene pubblicato).
- `pipeline/` — la procedura sul PC: PDF → testo pulito → audio con voci open source in locale.
- `output/` — audio e testi generati. Non viene mai pubblicato (vedi `.gitignore`).

I libri non vengono pubblicati: si importano nell'app dal telefono.
